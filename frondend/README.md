Premium flower bouquet e-commerce SPA for Sri Lanka — built with React 18, React Router v6, Tailwind CSS, and CSS Modules.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Routes

- `/` — Home
- `/shop` — Product catalog with filters
- `/product/:id` — Product detail
- `/gallery` — Portfolio gallery
- `/cart` — Shopping cart
- `/checkout` — Multi-step checkout (protected)
- `/track/:orderId` — Order tracking
- `/login` / `/register` — Authentication
- `/account` — User account (protected)
- `/admin` — Admin dashboard (admin only)

## Tech Stack

- React 18 + Vite
- React Router v6
- Tailwind CSS (layout utilities)
- CSS Modules (component styling)
- lucide-react (icons)
- recharts (admin analytics)
